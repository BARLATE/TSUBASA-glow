# 使ってはいけない表現（ng-expressions.md）

表現チェックの担当が、台本・テロップ・キャプション・DM の全部に当てる。見つけたら言い換え案を添えて差し戻す。
足すときは該当の表に1行足し、履歴に日付を書く。

## 薬機法（効き目を約束する言い方）

| 使わない | 言い換えの方向 |
| --- | --- |
| 治る／治す／改善する | 「僕は気にならなくなった」（体験として） |
| シミが消える／シワが消える | 使わない。見た目の感想に留める |
| 必ず／絶対／100% | 「僕の肌では」 |
| 肌が生まれ変わる | 使わない |
| ニキビが治る | 「ニキビができにくいと感じた」も避け、使用感の話にする |

## 雰囲気（voice.md の「言わない言葉」）

神アイテム／〜しか勝たん／爆速／マジで全員買って

## 書き方

- 商品やメーカーをけなさない。「〇〇はダメ」→「脂性肌の僕には合わなかった。理由は〜」
- 赤み・かゆみを、病気や治療の話にしない。

## 品質ルールで別に止める物（ここに書かなくても止まる）

- 根拠のない数字・事実（「最安」「No.1」「売上1位」など）は、出典がなければ事実確認の担当が止める（quality.md）。
- PR の表示がないアフィリエイトの投稿・DM は、表現チェックの担当が止める。
