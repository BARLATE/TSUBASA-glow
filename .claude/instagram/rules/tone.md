# トーンと構成（tone.md）

台本作成・フック作成・構成設計・台本レビューの担当が読む。話し方そのものは voice.md が正。ここは「構成の型」と使い分けのルール。

## トーン（2026-11-06 決定: おまかせ）

- 正直・辛口・テンポよく（voice.md と同じ）。AI 音声で読む前提。
- 決めつけない。必ず「脂性肌の僕の肌では」という体験として言う。

## 構成の型（4つを使い分ける）

| 型 | 流れ | 向いているネタ |
| --- | --- | --- |
| ① 結論型 | 結論 → 理由 → 僕の体験 → 合言葉 | 1つの商品・1つのやり方を言い切る時 |
| ② 失敗談型 | 失敗談 → 気づき → 今のやり方 → 合言葉 | 共感を取りたい時、新しい人に届けたい時 |
| ③ 比較型 | A と B、脂性肌に合うのはどっち → 結論 → 合言葉 | 迷われがちな2商品・2手順 |
| ④ ランキング型 | 合わなかった3つ／よかった3つ → 合言葉 | 保存されたい時、商品を複数紹介する時 |

## 使い分けのルール

- 同じ型を3本続けない（構成設計の担当が確認）。
- 商品を紹介する（アフィリエイトにつながる）回は ① か ③ か ④。② は信頼を積む回。
- 合言葉は最後の1回だけ。途中で何度もお願いしない。
