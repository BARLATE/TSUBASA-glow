# ワークフロー（workflow.md）

「リールを1本作って」と頼まれた時の流れ。実行は `/ig-team`（進行管理＝ig-28 の役をメインの Claude が担う）。

## 受付の質問（進行管理が、足りない物だけ1問ずつ聞く）

1. ネタは決まっているか（決まっていればそれ／なければリサーチから企画を出す）
2. 紹介する商品はあるか。あるなら商品名と、本人が実際に使ったか（使った／未使用／これから試す）
3. 構成の型の希望（①結論 ②失敗談 ③比較 ④ランキング／おまかせ）
4. 狙いの秒数（初期値 30秒）
5. 投稿の予定日

## 流れ

```
受付(28) → 0. 作業フォルダと 00-status.md を作る
1. リサーチ   01市場 → 02競合 → 03投稿収集 → 04トレンド → 05視聴者   ※30日以内の結果は再利用
2. 企画       06企画立案 → 07テーマ選定 ──【承認ゲート1: テーマ】
3. 台本       08構成 → 09フック → 10台本 → 11タイトル → 12CTA
4. レビュー   13台本レビュー → 14事実確認 → 15表現チェック ──【承認ゲート2: 台本】
                ↑ 差し戻しは 10台本へ（最大2回。3回目はユーザーに判断を仰ぐ）
5. 素材準備   16素材収集 → 17画像生成 → 18図解
6. 編集       19字幕 → 21音声調整 → 20動画編集
7. 確認・投稿 24キャプション → 22品質確認 → 23投稿管理 ──【承認ゲート3: 投稿】→ ユーザーが投稿
8. 分析・改善 （48時間後）25コメント分析 → 26数値分析 → 27改善提案 → 次の企画(06)と05視聴者へ
```

ネタが決まっている依頼でも、01〜05 は「再利用できる結果があるか」を確かめる。なければネタに関係する範囲だけ調べる。

## 役割が重なる所の線引き

| 重なり | 線引き |
| --- | --- |
| 市場調査 と 競合調査 | 市場＝需要・価格帯・悩みの言葉。競合＝見張るアカウントを決める |
| 競合調査 と 投稿収集 | 競合＝どのアカウントか。投稿収集＝その投稿を数字ごと集め、伸び倍率を出す |
| トレンド調査 と 投稿収集 | 投稿収集＝競合の投稿データ。トレンド＝季節・成分・新商品・見せ方の流行（出典付き） |
| 視聴者分析 と コメント分析 | コメント分析＝1投稿のコメントの分類と件数。視聴者分析＝それを積み上げて人物像にする |
| 企画立案 と テーマ選定 | 企画＝5案以上出す。テーマ＝1本に絞り、承認を取る |
| 構成設計 と 台本作成 | 構成＝段・役割・秒の配分。台本＝実際の文章 |
| フック作成 と タイトル作成 | フック＝話す1行目。タイトル＝カバー文字と冒頭の大テロップ |
| CTA設計 と キャプション作成 | CTA＝台本の締め・DM・リンクの道。キャプション＝投稿文（CTA の文を受け取って使う） |
| 台本レビュー・事実確認・表現チェック | レビュー＝見続けてもらえるか。事実＝根拠。表現＝薬機法・PR・AIっぽさ。どれも直さず指摘する |
| 画像生成 と 図解作成 | 画像＝カバーや写真の指示文。図解＝比較表・手順図などの情報の図 |
| 字幕作成・音声調整・動画編集 | 字幕＝文字と時刻。音声＝AI 音声と BGM。編集＝全部を1本のタイムラインにする |
| 品質確認 と レビュー3担当 | 品質確認＝投稿直前に完成品一式をチェックリストで判定。中身は直さない |
| 数値分析 と 改善提案 | 数値＝数字と通過率（事実）。改善＝打ち手（仮説）と確かめ方 |
| 進行管理 と 全員 | 進行管理は順番・質問・承認だけ。中身は書かない |

## 作業フォルダ

`.claude/instagram/work/YYYYMMDD-<短い名前>/` に `00-status.md` と各担当の `NN-*.md`。
