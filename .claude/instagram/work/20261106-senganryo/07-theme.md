## 3. 上位3案

### 1位: 案7「洗顔だけ変えて2週間、記録してみる。Day 0」（推し案）

- **内容:** 試し方の予告。化粧水など他は変えない／毎日同じ時間に使う／合わなかったら、合わなかったと正直に言う。今日はパッケージと泡だけ見せる。
- **型:** ① 結論型（結論＝「洗顔だけ変えて試す」）
- **狙う悩み:** 05-audience の 1（毛穴の黒ずみ）、3（洗顔を変えて荒れないか不安）※どちらも仮説
- **紹介する商品:** ラ ロッシュ ポゼ「エファクラ フォーミング クレンザー」125mL
- **使用状況:** 未使用。この回が試し始め。
- **選んだ理由:**
  1. 未使用であることが弱点にならない。「これから試す」がそのまま中身なので、使っていない商品を使ったように言ってしまう心配がいちばん小さい（quality.md #10）。
  2. 本人の数字がなくても成立する。化粧水にかけた金額などを言わなくても組める。
  3. 根拠が voice.md にそのまま書いてある（「使える実績」のネタの方向「洗顔だけ変えて2週間、記録してみる」、立場1・立場2）。
  4. 「合わなかったら正直に言う」は、voice.md の「正直で辛口」と、05 の悩み3（荒れないか不安）に合う（悩み3は仮説）。
  5. 続きの回（Day 14 など）につながる。実際に使った後の回なら、合った・合わなかったを体験として言えるので、商品を紹介する回として強くなる。
- **弱いところ:** この回は「まだ試していない」ので、見た人がすぐ買うよりも、結果の回を待つ流れになりやすい（収益は「○」）。この回の役目は、フォローと合言葉を取ること、と考える。
- **決まった場合にユーザーに聞くこと:**
  1. エファクラはもう手元にあるか（購入済みか）。いつから試し始めるか（Day 0 の日付）。
  2. 2週間、本当に「洗顔だけ」変えて、化粧水などほかは変えずに続けられるか。今使っているほかのスキンケアを画面に出すか・名前を言うか。
  3. 何を記録するか（例: 使った時刻、使った後のつっぱり感のメモ など）。肌は映さないので、記録の見せ方は手元・商品・メモに限る。
  4. 続きの回（Day 14 の結果報告）を出す予定でよいか。出す日の目安。
  5. 合言葉「毛穴」で送る DM の中身（下の「全案共通で聞くこと」1）。

### 2位: 案3「次の3,000円は化粧水と洗顔どっちに使う？ 僕は洗顔にする」

- **内容:** 化粧水と洗顔（2つの手順）を比べ、僕が洗顔を選ぶ理由 → エファクラを試すと宣言。
- **型:** ③ 比較型（2つの手順）
- **狙う悩み:** 05-audience の 1、2（仮説）
- **紹介する商品:** エファクラ フォーミング クレンザー 125mL
- **使用状況:** 未使用（これから試す）
- **選んだ理由:**
  1. 収益目標にいちばん近い。届けたい人の予算（2,000〜5,000円、voice.md）と商品の価格（公式 3,080円／Amazon 表示 2,970円、どちらも 2026-11-06 確認、01-market）と goals.md の仮の単価（3,000円）がそろっていて、「このお金をどこに使うか」という買う時の迷いに直接答える。
  2. ユーザー指定のネタ（高い化粧水より洗顔）をそのまま比べる形にできる。
  3. 本人の数字がなくても成立する。「3,000円」は商品の価格（出典あり）で、本人の数字ではない。
- **弱いところ:** 「僕は洗顔にする」の理由は、立場1（洗顔を変えたほうが効いた）の元の体験に頼る。その体験の中身が不明（06 不明点2）。エファクラの話と混ぜると、未使用の商品で効いたように聞こえる危険がある。化粧水をけなさない言い方が要る。
- **決まった場合にユーザーに聞くこと:**
  1. 立場1の元の体験: 前に何の洗顔に変えた時の話か、いつ頃か。台本で「前の体験」として言ってよいか。
  2. 「次は洗顔にお金を使う」は今の本人の本当の考えか（理由を本人の言葉で1〜2個）。
  3. 価格を言うなら、公式 3,080円と Amazon 表示 2,970円のどちらを使うか（言う場合は確認日を付ける。言わない選択もある）。
  4. （任意）化粧水にかけてきた金額・本数。なくても組めるが、あれば比べる材料になる。
  5. 合言葉「毛穴」で送る DM の中身（下の「全案共通で聞くこと」1）。

### 3位: 案5「高い化粧水をやめて洗顔を選び直す時、僕が見た3つ」

- **内容:** ①成分表（サリチル酸が入っているか）②予算に入るか ③楽天・Amazon どちらでも買えるか → 3つに当てはまったエファクラを試す。
- **型:** ④ ランキング型（選ぶ時に見た3つ）
- **狙う悩み:** 05-audience の 1、2（仮説）
- **紹介する商品:** エファクラ フォーミング クレンザー 125mL
- **使用状況:** 未使用（これから試す）。「使った感想」ではなく「選ぶ時に見た事」なので、未使用でも言える。
- **選んだ理由:**
  1. 出典がいちばん多い。成分（公式ページ・サンドラッグの全成分）、価格、楽天・Amazon で買えること（01-market）、サリチル酸の上限（厚生労働省の基準、04-trends B2）。
  2. 「見た3つ」は、見た人が自分で洗顔を選ぶ時にも使えるので、保存されやすい型（tone.md「④ 保存されたい時」）。保存は goals.md の流れの2段目。
  3. 本人の数字がなくても成立する。
- **弱いところ:** エファクラの区分（化粧品か医薬部外品か）と、上限の基準の最新版が未確認（01-market 不明点・04-trends 不明点）。確かめられないと ① の中身が薄くなる。上限の数字に「効く／安全」などの意味づけをしない注意が要る。「僕が見た3つ」が本人の実際の選び方と合っているかも未確認。
- **決まった場合にユーザーに聞くこと:**
  1. エファクラを選んだ時、実際にこの3つ（成分表・予算・買える場所）を見たか。違うなら、本人が実際に見た事に差し替える。
  2. 成分表は本人が読んだか（読んでいなければ「成分表を読んだだけ」とも言えないので、言い方を変える）。
  3. タイトルの「高い化粧水をやめて」は本人の事実か（本当にやめたのか、やめるつもりか）。
  4. 合言葉「毛穴」で送る DM の中身（下の「全案共通で聞くこと」1）。
