## 上位3案

### 1位: 案1「まだ使ってない僕が、低い評価から先に読んだ」（推し案）

- 内容: 良い声（泡・つっぱらない）と気になる声（刺激・毎日だと乾燥）を両方出し、「脂性肌的に、試すならこういう人」で締める
- 型: ① 結論型（結論＝向く人／迷う人 → 理由＝クチコミ → 僕の立場＝未使用・調べただけ → URL）
- 形式: スレッド4投稿（1: フック＋未使用の宣言＋PR／2: 良い声／3: 気になる声／4: 向く人・迷う人＋URL）
- 狙う悩み: 脂性肌のテカリ・皮脂、洗顔を変えて荒れないか不安
- 紹介する商品: ファンケル ディープクリア洗顔パウダー（`{{楽天のリンク}}`）
- 使用状況: 未使用（1投稿目で明示する）
- 選んだ理由:
  - 最後が「向く人」の結論なので、当てはまる人が URL を押す流れが作れる（収益に最も近い）
  - 01b の数字（4.69／7,553件、つっぱり20件中18件、泡53件、星1〜3 の87件中15件）と日付付きの引用だけで書ける
  - 「未使用」を隠さず最初に出すので、うそになる余地が小さく、voice.md の「正直・辛口・合わない話も出す」がそのまま初回の自己紹介になる
- 弱いところ:
  - 4投稿と長め。2投稿目以降が読まれないと URL まで届かない
  - 177件が低い評価に偏っている読み方を、短く正しく説明する必要がある（割合を全体の割合のように言わない）
  - 「向く人」の書き方が効き目の約束にならないよう、使用感（泡・つっぱり・頻度）で区切る必要がある
- 決まったら聞くこと:
  1. 1投稿目で「まだ使っていない」と言い切ってよいか
  2. `{{楽天のリンク}}` はどの種類（30個入り・セット等）のページにするか
  3. スレッド4投稿でよいか（短くしたい場合は3投稿に詰める）
  4. （任意）この商品を今後買って試す予定があるか（あれば最後に「試したらまた書く」と一言足せる）

### 2位: 案4「正直、このクチコミは僕らの年代の声が少ない」

- 内容: 年代を書いた人は30〜50代が中心（読んだ範囲で10代2件・20代6件）。点数をそのまま信じず、20代と脂性肌の人の声だけ拾って紹介する
- 型: ① 結論型
- 形式: スレッド3投稿（1: フック＋PR／2: 年代の内訳と読み方／3: 20代男性の声・脂性肌の人の声＋URL）
- 選んだ理由:
  - 「高評価でも自分に合うかは別」という切り口が他の紹介アカウントと違い、初回で立場が伝わる
  - 01b 1章の内訳と、日付付きの引用（20代男性の良い声・気になる声、脂性肌の声）で書ける
  - 未使用でも「クチコミの読み方」の話なので、体験を書かずに成り立つ
- 弱いところ:
  - 「この年代の声は少ない」が前に出るため、買う後押しが弱く、クリックは案1より落ちる見込み（推測）
  - 20代の声が6件と少なく、拾える声が限られる（増やすなら 01 の読み足しが要る）
  - 「狙う悩み」の一部（点数が高くても合うか分からない）は出所のない仮説
- 決まったら聞くこと:
  1. 年代の偏りを前面に出してよいか（売りにくくなる可能性を了承するか）
  2. 20代の声を増やすため、市場調査（01）に読み足しを頼むか、今の件数で書くか
  3. `{{楽天のリンク}}` の種類

### 3位: 案3「楽天のクチコミで見つけた、買う前に知っておきたい3つ」

- 内容: (1) 泡はネットで立てたという声 (2) 毎日だと乾燥気味で数日おきにしている人がいる (3) 洗っているとネットが黒くなるのが嫌という声
- 型: ④ ランキング型（知っておきたい3つ）
- 形式: スレッド5投稿（短くするなら3投稿）
- 選んだ理由:
  - 買う前の実用情報なので、保存されやすく、買う気のある人がそのまま URL へ進みやすい
  - 3つとも 01b の日付付きの引用で書ける。未使用でも「こう書いた人がいた」で成立する
- 弱いところ:
  - (3)「ネットが黒くなる」は、読む人が「汚れが取れている」と受け取りやすく、効き目の言い方に近づく
  - 使う頻度の話は「週◯回が正解」と言えない（出典なし）ので、結論がぼやけやすい
  - 5投稿だと長く、初回の「この人は何者か」は案1ほど伝わらない
- 決まったら聞くこと:
  1. (3)「ネットが黒くなる」の声を入れるか、別の声に替えるか
  2. 5投稿か、3投稿に詰めるか
  3. `{{楽天のリンク}}` の種類
