## 3. Threads での投稿手順（4投稿をつなげてスレッドにする）

アプリの画面の細かい表示（ボタンの名前・位置）は、この環境からは確かめられません。下は一般的な流れです。**実際の操作はアプリの表示に従ってください。**

1. 上の U1〜U6 と P3 を済ませる（U1・U4 が「未」なら、ここで止める）。
2. Threads アプリを開き、@lte.skincare でログインしていることを確かめる（ログインはユーザーが行う）。
3. 新しいスレッドを作る画面を開く（アプリの表示に従う）。
4. 1つ目の入力欄に、下の「投稿1」の本文をそのまま貼る。
5. スレッドに投稿を足す操作（「スレッドに追加」のような表示。アプリの表示に従う）で2つ目の入力欄を出し、「投稿2」を貼る。
6. 同じように3つ目に「投稿3」、4つ目に「投稿4」を貼る。
7. 投稿4の URL が押せるリンクとして扱われているか、プレビューで見る（リンクのカードが出る場合も、PR の行が本文に残っていればよい）。
8. P1〜P4 を見てから、4投稿をまとめて投稿する。
   - もし4つを一度にまとめて投稿する操作が見つからない時は、投稿1を投稿したあと、自分の投稿1に返信する形で投稿2、投稿2に返信する形で投稿3…とつなげる方法もある（{{要確認: Threads でスレッドを作る正式な操作}}。アプリの表示に従う）。
9. 投稿した日時（年月日・時刻）を、下の「5. 承認と記録」に書く。

ピン留め: 今回は不要の予定（このアカウントで最初の商品紹介のため、プロフィールの先頭に固定するかは、数字を見てから決める）。{{要確認: Threads にプロフィールへの固定の機能があるか}}
