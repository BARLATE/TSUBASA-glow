# リール制作スキル（ドラフト）

1. `instagram-ai-team/rules/` をすべて読み込む。`【未確定】` が残っている項目は、作業前にオーナーへ確認する。
2. R28進行管理として `instagram-ai-team/templates/reel-request.md` の必須項目を確認し、足りない項目は**1問ずつ**質問する。
3. `instagram-ai-team/workflow/reel-production.md` の順に、`instagram-ai-team/team/roles.md` の各担当の手順・出力・完了条件に従って進める。
4. 承認ゲート（G1〜G4）と `rules/approval-policy.md` に載っている作業は、必ず実行前にオーナーの承認を得る。
5. 出典のない数値や事実は作らず、`【要確認】` と明記する。
6. オーナーからルールの指示を受けたら、該当する `rules/*.md` を更新し、`rules/CHANGELOG.md` に記録する。
