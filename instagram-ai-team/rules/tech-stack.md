# 実行環境（ツール・API）

> 最終更新: 2026-11-10 ／ 根拠: Q19「2：API連携で投稿まで自動化する」
> 下の要件は、一般的な情報をもとにした**仮の整理**。すべて R14 が公式ドキュメントで確認してから着手する【要確認】。

## 構成案
| 工程 | 自動化の方法（案） | 状態 |
|---|---|---|
| 台本・投稿文・字幕（.srt） | AIが生成し、ファイルとして保存 | すぐに可能 |
| 図解・カバー画像 | 画像生成API、またはプログラムで作図（HTML・SVGから画像化） | ツールは【未確定】 |
| ナレーション | オーナーの録音、または音声合成（TTS） | 【未確定】 |
| 動画の組み立て | プログラムで編集（例：ffmpeg、Remotionなど） | ツールは【未確定】 |
| Instagramへの投稿 | Instagram Graph API（リールの公開） | 準備が必要 |
| Threadsへの投稿 | Threads API | 準備が必要 |
| 指標の取得 | 各APIのインサイト取得機能 | 取得できる項目は【要確認】 |

## API連携の準備チェックリスト（すべて【要確認】、オーナーの作業を含む）
- [x] Instagramアカウントの状態 → 既存のアカウントを使う（Q20）
- [ ] 既存の投稿テーマが新しい発信（Threadsの実践記録）と合うかを確認する（合わない場合の扱いはオーナーが判断）
- [ ] Instagramをプロアカウント（ビジネス or クリエイター）にする
- [ ] Meta for Developers でアプリを登録し、必要な権限を申請する（Facebookページとの連携が必要かどうかは方式によって異なる【要確認】）
- [ ] Threadsアカウントを作成し、Threads APIの利用設定をする
- [ ] リールをAPIで投稿するには、動画を公開URLに置く必要があるかどうか、その置き場所【要確認】
- [ ] APIの投稿数の上限と、使える動画の仕様（尺・サイズ・形式）を確認する
- [ ] アクセストークンの有効期限と更新方法を確認する

## セキュリティのルール
- アクセストークンやAPIキーは、**このリポジトリに書かない・コミットしない**。実行環境の秘密情報（環境のシークレット）として保存する
- トークンの発行・登録はオーナーが行う（🔒 外部サービスとの連携のため承認が必要）
- APIによる投稿は、G4の承認を得たものだけを実行する。予約投稿の登録も同様

## 移行方針
- API連携の準備が整うまでは、AIが素材一式と指示書を作り、オーナーが手動で投稿する（暫定運用）
