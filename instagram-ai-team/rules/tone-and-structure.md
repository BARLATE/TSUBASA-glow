# トーンと構成のルール

> 最終更新: 2026-11-10 ／ ステータス: 候補3パターンを提示中（Q6「4：お手本はないので、AIがたたき台を作る」）→ オーナーの選択待ち
> サンプル台本の中身はトーンを伝えるための例です。収入額や実績の数値は入れていません。

## 3パターン共通のルール
- 冒頭（0〜3秒）はターゲットの悩みか結論で始める。「稼げる」を見出しにしない（`rules/ng-expressions.md`）
- CTAは「プロフィール → リンク」へつなぐ（`rules/kpi.md`）
- 1画面のテロップは1メッセージにする

---

## パターンA：等身大の実践者（共感・体験型）

| 項目 | 内容 |
|---|---|
| 話し方 | 友達口調／落ち着いたテンション |
| 一人称 | 「私」または「僕」【選択】 |
| 標準の尺 | 30〜45秒 |
| 構成 | 共感フック → 自分のつまずき → 気づき（結論）→ やり方2〜3個 → CTA |
| 向いている企画 | 初心者の悩みの解消、失敗談、日々の実践記録 |
| 注意 | 体験談は事実だけを書く（C4）。実績を出す場合は根拠資料が必要 |

**サンプル（約35秒）**
| 秒 | ナレーション | テロップ |
|---|---|---|
| 0-3 | 「Threads始めたけど、何を投稿すればいいか分からない…って人いない？」 | 何投稿すればいい？ |
| 3-10 | 「私も最初は、思いついたことを書いては反応ゼロ、を繰り返してた」 | 最初は反応ゼロ |
| 10-15 | 「変わったのは、“誰に向けて書くか”を一人に決めてから」 | 届ける相手を1人に決める |
| 15-30 | 「やったのは3つ。①プロフィールに“誰の役に立つか”を書く ②その人の悩みに1投稿1つ答える ③他の人の投稿にちゃんとコメントする」 | ①プロフィール ②1投稿1悩み ③交流 |
| 30-35 | 「私がやったことは、プロフィールのnoteに全部まとめてるよ」 | 詳しくはプロフィールのnoteへ |

## パターンB：解説者（ノウハウ・信頼型）

| 項目 | 内容 |
|---|---|
| 話し方 | 丁寧語（です・ます）／落ち着いたテンション |
| 一人称 | 「私」／基本的に使わない |
| 標準の尺 | 45〜60秒 |
| 構成 | 結論を先に言う → 理由 → 手順（図解）→ 注意点 → まとめ → CTA |
| 向いている企画 | 仕組みの解説、手順の解説、ツールの使い方、比較 |
| 注意 | 制度や機能の説明は、公式情報で事実確認をする（R14） |

**サンプル（約50秒）**
| 秒 | ナレーション | テロップ |
|---|---|---|
| 0-4 | 「Threadsで副収入を目指すなら、最初にやるべきは“投稿”ではなく“設計”です」 | 最初にやるのは“設計” |
| 4-14 | 「理由は、誰に何を届けるかが決まっていないと、フォローされる理由が生まれないからです」 | フォローされる理由をつくる |
| 14-38 | 「手順は3つ。1.発信テーマを1つに絞る 2.ターゲットの悩みを10個書き出す 3.悩み1つにつき1投稿で答える」 | 手順3ステップ（図解） |
| 38-45 | 「注意点として、収益化の方法は規約や制度が変わることがあります。公式の情報を必ず確認してください」 | 規約は公式で確認 |
| 45-50 | 「悩みの書き出し方は、プロフィールのnoteで詳しく解説しています」 | 詳しくはプロフィールのnoteへ |

## パターンC：テンポ重視（リスト・保存型）

| 項目 | 内容 |
|---|---|
| 話し方 | 短い文の言い切り／明るく速いテンポ |
| 一人称 | ほぼ使わない |
| 標準の尺 | 15〜30秒 |
| 構成 | タイトルで提示（〇選）→ 項目を1つずつ表示 → 保存とプロフィールへの誘導 |
| 向いている企画 | 〇選、チェックリスト、やってはいけないこと、ツールの紹介 |
| 注意 | テンポのために断定を強めすぎない（誇大表現に注意） |

**サンプル（約25秒）**
| 秒 | ナレーション | テロップ |
|---|---|---|
| 0-3 | 「Threads初心者が最初の1週間でやること、3つ」 | 最初の1週間でやること3選 |
| 3-9 | 「1つ目、プロフィールで“誰の役に立つか”を書く」 | ①プロフィール |
| 9-15 | 「2つ目、1投稿で1つの悩みに答える」 | ②1投稿1悩み |
| 15-21 | 「3つ目、同じジャンルの人の投稿に毎日コメント」 | ③毎日コメント |
| 21-25 | 「保存して見返してね。続きはプロフィールのnoteで」 | 保存＆プロフィールのnoteへ |

## 確定後に記入する項目
- 採用パターン: 【未確定】（A／B／C、または組み合わせ）
- 一人称・呼びかけ（「みんな」「あなた」など）: 【未確定】
- 標準の尺: 【未確定】
- 話す速さ（文字/秒）: 【未確定】（尺の計算に使う）
