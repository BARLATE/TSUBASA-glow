# 責任範囲の整理（重複しやすい役割）

R=実行、A=最終責任、C=相談先、I=共有先

| 論点 | 担当（R/A） | 関係者 | 境界線 |
|---|---|---|---|
| 競合の分析 | R02（アカウント単位） | R03（個別投稿） | R02は「誰が・なぜ強いか」、R03は「どの投稿が・どんな型か」 |
| トレンドと投稿収集 | R04（流行の判定） | R03（データ化） | R04は旬の判断、R03は記録 |
| 企画の採否 | R07（A） | R06（R） | R06は案を出すだけで、採否はR07＋オーナー |
| 冒頭の文言 | R09 | R08, R10 | R08は秒数枠、R09は文言、R10は台本へ組み込む |
| タイトルとキャプション | R11（動画内・カバー） | R23（投稿本文） | 文言の一貫性はR13が確認 |
| CTA | R12（設計） | R10, R23（組み込み） | 文言を変えるときはR12に相談 |
| レビューの判定 | R13（内容）/R14（事実）/R15（表現） | — | それぞれ独立した拒否権を持ち、R13は他の判定を上書きしない |
| 新規素材 | R17（画像）/R18（図解） | R16 | 既存素材があればR16、なければR17・R18 |
| 字幕の文言 | R19 | R13 | 台本の修正はR13経由に限る |
| 音と最終品質 | R21（音） | R22（A：全体判定） | R22が不合格なら該当担当へ差し戻す |
| 数値と提案 | R26（事実・仮説） | R27（施策） | R27は数値を再計算しない |
| オーナーへの質問・承認 | R28（窓口を一本化） | 全担当 | 担当が直接オーナーへ質問せず、R28がまとめて聞く |
