```

          │

                   ├ R04 トレンド
                   └ R05 視聴者          ※既存の調査が有効期限内なら省略可【未確定：有効期限】
          │
② 企画      R06 企画立案 ─▶ R07 テーマ選定 ─▶ 🔒G1 オーナー承認（テーマ）
          │

```

## 受付時の確認項目（R28が依頼票で確認）

| 項目 | 必須 | 未記入のとき |
|---|---|---|
| テーマ・ネタ（あれば） | 任意 | リサーチ→企画から開始 |
| 目的・狙うKPI | 任意 | `rules/kpi.md` のフェーズ1の指標（保存・プロフィールアクセス・フォロー） |
| ターゲット | 任意 | `research/audience.md`（未作成ならR05が作成） |
| 尺 | 任意 | `rules/tone-and-structure.md` の標準値 |
| 投稿希望日 | 任意 | R24が提案 |
| 実践記録の元ネタ（今週やったこと） | 実践記録の回は必須 | 週次定例の聞き取り記録を使い、なければオーナーへ質問 |
| 使ってよい予算（素材・ツール） | 必須（初回のみ） | 0円として進め、費用が必要なら承認依頼 |

※ 確定済みの前提（毎回は聞かない）: トーンはパターンA・一人称「僕」・尺30〜45秒、AI音声でナレーション、顔出しなし、Threads投稿文もセットで作る

## 承認ゲート

| ゲート | タイミング | オーナーに見せるもの |
|---|---|---|
| G1 | テーマ決定 | 上位3案と選定理由 |
| G2 | 台本確定 | 台本、事実確認の結果、表現チェックの結果、`【要確認】` の一覧 |
| G3 | 完成動画 | 動画、QAチェックリスト、Threads投稿文 |
| G4 | 投稿実行 | 最終動画、キャプション、投稿日時 |
| GT | 週次（日曜） | 翌週分のThreadsだけの投稿 |
| 随時 | 費用の発生、外部送信、ルール変更、コメント返信、有料化 | 内容と理由 |

> 承認ゲートはQ18で確定した（`rules/approval-policy.md`）。
