# ワークフロー：「リールを1本作って」

```
依頼 ─▶ R28 受付・不足情報の確認
          │
① リサーチ  R01 市場 ┬ R02 競合 ─ R03 投稿収集
                   ├ R04 トレンド
                   └ R05 視聴者          ※既存の調査が有効期限内なら省略可【未確定：有効期限】
          │
② 企画      R06 企画立案 ─▶ R07 テーマ選定 ─▶ 🔒G1 オーナー承認（テーマ）
          │
③ 台本      R08 構成 ─▶ R09 フック / R11 タイトル / R12 CTA（並行）─▶ R10 台本
          │
④ レビュー  R13 台本レビュー ＋ R14 事実確認 ＋ R15 表現チェック（並行）
            差し戻しループ ─▶ 🔒G2 オーナー承認（台本）
          │
⑤ 素材準備  R16 素材収集 ─▶ 不足分は R17 画像 / R18 図解   ※有料素材は🔒承認
          │
⑥ 編集      R19 字幕 ─▶ R20 動画編集 ⇄ R21 音声調整
          │
⑦ 品質確認  R22 品質確認 ─▶ 🔒G3 オーナー承認（完成動画）
            R23 キャプション ─▶ R24 投稿管理 ─▶ 🔒G4 オーナー承認（投稿の実行）
          │
⑧ 分析      R25 コメント分析 / R26 数値分析（計測タイミング【未確定】）
          │
⑨ 改善提案  R27 改善提案 ─▶ ルール変更案は🔒承認 ─▶ 次サイクルの R06 へ
```

## 受付時の確認項目（R28が依頼票で確認）

| 項目 | 必須 | 未記入のとき |
|---|---|---|
| テーマ・ネタ（あれば） | 任意 | リサーチ→企画から開始 |
| 目的・狙うKPI | 必須 | オーナーへ質問 |
| ターゲット | 必須（初回のみ） | `research/audience.md` を使用、なければ質問 |
| 尺 | 任意 | `rules/tone-and-structure.md` の標準値 |
| 投稿希望日 | 任意 | R24が提案 |
| 顔出し・ナレーションの有無、手持ち素材 | 必須（初回のみ） | オーナーへ質問 |
| 使ってよい予算（素材・ツール） | 必須（初回のみ） | 0円として進め、必要なら承認依頼 |

## 承認ゲート

| ゲート | タイミング | オーナーに見せるもの |
|---|---|---|
| G1 | テーマ決定 | 上位3案と選定理由 |
| G2 | 台本確定 | 台本、事実確認の結果、表現チェックの結果、`【要確認】` の一覧 |
| G3 | 完成動画 | 動画、QAチェックリスト |
| G4 | 投稿実行 | 最終動画、キャプション、投稿日時 |
| 随時 | 費用の発生、外部送信、ルール変更、コメント返信 | 内容と理由 |

> 承認ゲートの数・省略可否は【未確定】（ヒアリング後に `rules/approval-policy.md` で確定）。
